Hello, and thank you for the review. Our answers, in the order you asked:

QUESTION 1: "Are users able to see other users' locations in your app?"
ANSWER: No. The app never shows any member's location to another member. The server compares locations privately only to decide whether a sighting is within 50 meters. The only place information other members see is the city and state of a recorded sighting.

QUESTION 2: "How do users raise questions?"
ANSWER: There are no questions in this app. It is a group experiment, not a Q and A app. Each day a few random members are picked. A picked member can ask one random other member to hold their right hand up. The asked member gets a notification and has 20 minutes. Anyone nearby who sees a raised right hand taps "I saw a raised hand". If they are within 50 meters of the asked member, the sighting is recorded and the "time since last sighting" clock resets.

QUESTION 3: "We were unable to ask random questions in live mode while we were using 2 devices in the same location/spot."
ANSWER: You are right, and thank you for pointing it out. The daily pick is random (about 3%), so a review device is almost never picked. We added a live test mode for review. On BOTH devices:
1. Tap "App Review? Enter code" at the bottom of the screen, type APPLE-REVIEW, and tap "Live test with two devices". Each device is now a review test member that is always picked.
2. On device 1, tap "Ask a random member to raise their right hand". The request goes only to your other review device.
3. On device 2, allow notifications and location. It shows a countdown. Hold the right hand up. Location is shared only during the 20-minute window.
4. On device 1, within 50 meters, tap "I saw a raised hand". A match message appears.
Review test activity is kept separate from real members and does not change the public counter. The screens-only demo is still available with the same code.

QUESTION 4: "How can users add questions and answers?"
ANSWER: They cannot, because there are no questions or answers in the app. See the answer to question 2.

Please let us know if anything else is needed. Thank you!
